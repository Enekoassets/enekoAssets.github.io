CtrlIdle


Controllable Idle Motion Generation With Flow Matching

Eneko Atxa Landa • Igor Rodriguez • Elena Lazkano • Gustav Eje Henter
📄 Arxiv Preprint 💻 GitHub

Abstract

Idle behaviour is a central characteristic of video game NPCs and virtual characters. Creating these animations is part of nearly every pipeline of video game and virtual experience development. Recent advances in generative modelling have enabled generating many types of animations, such as locomotion or co-speech gestures, albeit no works have explored the use of deep-learning to generate idle animations. In this paper, we present CtrlIdle, the first generative system that allows to generate idle animations and enables to control the generative process with input signals that are easy to use and understand for the end user. It is trained using conditional flow matching (CFM), which permits to generate diverse animations stochastically, providing different outputs for the same control signals. We use both numerical and user-based evaluations to measure the quality of the generated output and the effectiveness of the control system.

Features

- First model to generate idle animations.

- Stochastic generation:

Generate new and different animations every time, thanks to flow matching.

- Control system: specific for idle animations

- Pose control: Generate the motion conditioned on a reference pose.

- Speed control: Guide motion using a 6 target speed control system.
